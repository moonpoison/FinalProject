# AutoFlow 시스템 아키텍처

## 1. 시스템 개요

AutoFlow는 비개발자도 쉽게 사용할 수 있는 AI 기반 업무 자동화 플랫폼입니다.
드래그 앤 드롭 방식의 블록 빌더와 Claude AI를 활용한 자연어 기반 자동화 생성 기능을 제공합니다.

## 2. 기술 스택

### 프론트엔드
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **Drag & Drop**: dnd-kit
- **State Management**: React Context API

### 백엔드
- **Framework**: FastAPI (Python 3.11+)
- **Database**: SQLite + SQLAlchemy (Async)
- **Authentication**: JWT (python-jose)
- **AI**: Anthropic Claude API
- **Password Hashing**: bcrypt (passlib)

## 4. 데이터베이스 스키마

### 4.1 Users 테이블
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | String (UUID) | 기본 키 |
| email | String | 이메일 (고유) |
| hashed_password | String | 암호화된 비밀번호 |
| name | String | 사용자 이름 |
| role | Enum | buyer/seller |
| avatar | String | 프로필 이미지 |
| joined_at | DateTime | 가입일 |

### 4.2 MarketplaceItems 테이블
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | String (UUID) | 기본 키 |
| title | String | 제목 |
| description | Text | 설명 |
| category | String | 카테고리 |
| price | Integer | 가격 (0=무료) |
| rating | Float | 평점 |
| downloads | Integer | 다운로드 수 |
| creator_id | String (FK) | 제작자 ID |
| blocks_data | JSON | 블록 데이터 |
| tags | JSON | 태그 목록 |
| status | String | 상태 (active/draft/suspended) |

### 4.3 Purchases 테이블
| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | String (UUID) | 기본 키 |
| buyer_id | String (FK) | 구매자 ID |
| item_id | String (FK) | 아이템 ID |
| price | Integer | 구매 가격 |
| status | Enum | pending/active/cancelled |
| deadline | DateTime | 구매 확정 기한 |
| purchased_at | DateTime | 구매일 |

### 4.4 Conversations & Messages 테이블
채팅 기능을 위한 대화 및 메시지 관리

### 4.5 Reviews 테이블
아이템 리뷰 관리

### 4.6 Templates 테이블
사용자의 자동화 템플릿 관리

## 5. 인증 흐름

```
1. 회원가입/로그인 요청
       ↓
2. 비밀번호 검증 (bcrypt)
       ↓
3. JWT 토큰 생성
       ↓
4. 클라이언트에 토큰 반환
       ↓
5. 이후 요청시 Authorization 헤더에 Bearer 토큰 포함
       ↓
6. 서버에서 토큰 검증 후 사용자 정보 반환
```

## 6. AI 통합

### Claude API 활용
1. 사용자가 자연어로 자동화 작업 설명
2. Claude API로 분석 요청 전송
3. AI가 워크플로우 구조 설계 (그룹, 단계, 블록 타입)
4. 결과를 미리보기로 표시
5. 사용자 승인 후 실제 블록으로 변환

### 지원 블록 타입
- **시작**: start, schedule
- **브라우저**: open-site, navigate, scroll, screenshot
- **마우스**: click, double-click, hover
- **키보드**: input-text, press-key
- **데이터**: extract-text, extract-list, save-excel
- **제어**: wait, loop, condition
- **API**: http-request, send-email, send-slack

## 7. 보안 고려사항

1. **비밀번호**: bcrypt 해싱 사용
2. **JWT**: 7일 만료, 서명 검증
3. **CORS**: 허용된 Origin만 접근 가능
4. **SQL Injection**: SQLAlchemy ORM 사용으로 방지
5. **API Key**: 환경변수로 관리
