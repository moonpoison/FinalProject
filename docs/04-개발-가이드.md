# AutoFlow 개발 가이드

## 1. 개발 환경 설정

### 1.1 필수 요구사항
- Python 3.11+
- Node.js 18+
- pnpm (또는 npm)

### 1.2 백엔드 설정

```bash
# 백엔드 디렉토리로 이동
cd backend

# 가상환경 생성 (권장)
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 또는
venv\Scripts\activate  # Windows

# 의존성 설치
pip install -r requirements.txt

# 환경변수 설정
cp .env.example .env
# .env 파일을 열어 ANTHROPIC_API_KEY 설정

# 서버 실행
python run.py
```

### 1.3 프론트엔드 설정

```bash
# 프로젝트 루트에서
pnpm install

# 환경변수 설정
echo "NEXT_PUBLIC_API_URL=http://localhost:8000/api" > .env.local

# 개발 서버 실행
pnpm dev
```

## 3. API 개발 가이드

### 3.1 새 API 엔드포인트 추가

1. `app/schemas/`에 요청/응답 스키마 정의
2. `app/api/`에 라우터 생성
3. `app/api/__init__.py`에 라우터 등록

예시:
```python
# app/schemas/example.py
from pydantic import BaseModel

class ExampleCreate(BaseModel):
    name: str
    value: int

class ExampleResponse(BaseModel):
    id: str
    name: str
    value: int

# app/api/example.py
from fastapi import APIRouter, Depends
from app.schemas.example import ExampleCreate, ExampleResponse
from app.utils.security import get_current_user

router = APIRouter()

@router.post("", response_model=ExampleResponse)
async def create_example(
    data: ExampleCreate,
    current_user = Depends(get_current_user)
):
    # 로직 구현
    pass

# app/api/__init__.py
from app.api import example
api_router.include_router(example.router, prefix="/examples", tags=["예시"])
```

### 3.2 데이터베이스 마이그레이션

현재는 자동 마이그레이션을 사용합니다. 서버 시작 시 `init_db()`가 테이블을 생성합니다.

프로덕션에서는 Alembic 사용을 권장합니다.

## 5. 배포

### 5.1 백엔드 배포 (예: Railway, Render)

```dockerfile
# Dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 5.2 환경변수 설정

프로덕션에서 설정해야 할 환경변수:
- `SECRET_KEY`: 랜덤한 강력한 키
- `ANTHROPIC_API_KEY`: Claude API 키
- `DATABASE_URL`: 프로덕션 DB URL
- `DEBUG`: False
- `CORS_ORIGINS`: 프로덕션 프론트엔드 URL

## 6. 문제 해결

### 6.1 CORS 에러

`app/config.py`의 `CORS_ORIGINS`에 프론트엔드 URL 추가

### 6.2 데이터베이스 초기화

```bash
# SQLite 파일 삭제 후 재시작
rm autoflow.db
python run.py
```

### 6.3 Claude API 에러

- API 키 확인
- 요청 제한 확인
- 모델 이름 확인 (config.py의 CLAUDE_MODEL)
